# Разметка датасета по текстовым подсказкам (GroundingDINO + SAM)

Веб-приложение для быстрой разметки изображений и видео: пользователь вводит
текстовый запрос (например, `airplane`), а приложение автоматически находит
и сегментирует все подходящие объекты, с возможностью ручной коррекции масок
и экспорта в форматы **COCO**, **YOLO**, **Pascal VOC**.

## Структура проекта

```
grounded_segmentation_app/
├── app.py                  # Точка входа — Gradio-интерфейс
├── config.py                # Настройки (модели, пороги, пути, лимиты)
├── requirements.txt
├── core/
│   ├── detector.py           # Обёртка над GroundingDINO (детекция по тексту)
│   ├── segmenter.py          # Обёртка над SAM (сегментация по боксу)
│   ├── pipeline.py           # Связка "текст -> боксы -> маски"
│   ├── video_processor.py    # Извлечение кадров из видео по интервалу
│   └── exporters.py          # Экспорт в COCO / YOLO / Pascal VOC
└── utils/
    ├── image_utils.py        # Отрисовка масок/боксов, ручное редактирование
    ├── file_utils.py         # Работа с временными папками и zip-архивами
    └── logger.py              # Единая настройка логирования
```

## Установка

Рекомендуется Python 3.10+ и отдельное виртуальное окружение.

```bash
python3.10 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install --upgrade pip
pip install -r requirements.txt
```

**GPU (рекомендуется):** если на машине есть NVIDIA GPU и установлен CUDA
Toolkit, замените строку `torch`/`torchvision` в `requirements.txt` на
команду с сайта https://pytorch.org/get-started/locally/, соответствующую
вашей версии CUDA — иначе PyTorch может установиться в CPU-варианте.

Первый запуск скачает веса моделей GroundingDINO и SAM с HuggingFace Hub
(несколько сотен мегабайт — нужен доступ в интернет). Модели кэшируются
в `~/.cache/huggingface`, повторные запуски будут быстрее.

## Запуск

```bash
python app.py
```

Приложение будет доступно по адресу `http://localhost:7860`.

## Использование

1. **Одно изображение** — загрузите картинку, введите текстовый запрос,
   настройте пороги при необходимости, нажмите «Разметить». Результат можно
   скорректировать вручную (кисть/ластик) для выбранного объекта, затем
   сохранить разметку в нужных форматах.
2. **Пакетная обработка** — загрузите несколько изображений, задайте один
   запрос для всех, получите общий zip-архив с изображениями и аннотациями.
3. **Видео** — загрузите видеофайл и интервал в секундах: кадры будут
   извлечены равномерно и размечены тем же способом, что и изображения.

### Важно про формулировку запроса

GroundingDINO обучен на англоязычных парах "изображение-текст", поэтому
**запросы на английском языке работают значительно надёжнее**, чем на
русском (например, используйте `airplane`, а не «самолёт»). Для нескольких
классов сразу разделяйте их точкой: `airplane. car. person.`

## Известные ограничения и точки отказа

- **Пороги детекции.** Слишком низкий `box_threshold` даёт много ложных
  срабатываний, слишком высокий — пропускает реальные объекты. Значения по
  умолчанию (0.35 / 0.25) — компромисс, для конкретного датасета их стоит
  подобрать заново.
- **Общие/абстрактные запросы** (например, «объект», «вещь») могут привести
  к сотням совпадений на сложных сценах — в коде есть защитный лимит
  `MAX_DETECTIONS_PER_IMAGE` (см. `config.py`), но качество разметки в таких
  случаях всё равно будет низким.
- **YOLO и Pascal VOC не хранят полигоны сегментации** — только bounding box,
  вычисленный как ограничивающий прямоугольник маски. Полноценная маска
  (полигон) сохраняется только в формате COCO.
- **Видео с переменным FPS** (характерно для некоторых файлов с телефонов):
  извлечение кадра по номеру `round(fps * t)` может давать небольшое
  расхождение с реальной временной меткой.
- **Видео без корректных метаданных FPS** обрабатываться не будет — вместо
  тихого использования произвольного FPS приложение явно сообщает об ошибке,
  чтобы не создавать неверно размеченный датасет.
- **Ручное редактирование масок** реализовано через рисование белым (добавить)
  и чёрным (стереть) поверх маски; в пакетном режиме и для видео ручная
  правка не предусмотрена — только для одиночных изображений, точечно.
- **Производительность на CPU.** Без GPU обработка каждого изображения может
  занимать десятки секунд; для больших пачек и длинных видео настоятельно
  рекомендуется CUDA.
- **Ограничение MAX_VIDEO_FRAMES** (по умолчанию 500) защищает от случайного
  извлечения тысяч кадров при малом интервале на длинном видео — при
  необходимости увеличьте значение в `config.py`, оценив требуемую память и время.
- **Многопользовательский доступ.** Модели загружаются один раз в память
  процесса и являются общими для всех сессий Gradio; при интенсивном
  параллельном использовании запросы будут выполняться последовательно
  (очередь `demo.queue()`), а не по-настоящему параллельно на одном GPU.

## Изменение моделей

В `config.py` можно переопределить используемые модели через переменные
окружения, например для более точной (но медленной и требовательной к
видеопамяти) версии:

```bash
export GROUNDING_DINO_MODEL_ID="IDEA-Research/grounding-dino-base"
export SAM_MODEL_ID="facebook/sam-vit-huge"
python app.py
```
